BIOS 设置（收益最大，先做）

任务清单

开启内存 EXPO 白捡性能
开机狂按 Del 进 BIOS → OC → EXPO/A-XMP → 选 EXPO 配置文件 1 → F10 保存。验证：任务管理器内存显示 5600 MT/s（不是4800）。
开启 PBO 9800X3D 免费性能
OC 菜单里找 PBO（Precision Boost Overdrive）→ Enabled。温度余量大，随便开。
更新 BIOS 到最新 X870E 必做
M-FLASH 流程：官网下载（MPG X870E CARBON WIFI）→ U盘 FAT32 根目录 → Del 进 BIOS → M-FLASH → 选文件刷写 → 更新后 F6 恢复默认。过程中绝对不能断电。

BIOS 更新三种方法

方法说明
A. M-FLASH（最推荐）U盘 FAT32 → 官网下载 BIOS 解压到根目录 → BIOS 内 M-FLASH → 选文件 → 等待完成 → F6 恢复默认
B. MSI Center 在线（最简单）MSI Center → 技术支持 → 在线更新 → 高级更新 → BIOS → 更新。黑屏几次正常，等自动完成
C. 无U刷新（救砖）IO 挡板 Flash BIOS Button，无需 CPU/内存，日常用不到

视频教程：B站搜"微星 BIOS 更新 M-FLASH"（微星官方频道）；YouTube 搜 "MSI MAG X870E TOMAHAWK WIFI BIOS Update"；抖音搜"微星x870e暗黑主板更新bios"。

警告刷写过程中绝对不能断电；更新前可用 M-FLASH 备份当前版本。

Windows 11 游戏优化清单

第一梯队：白捡大性能

关闭内存完整性（VBS） 最多 +15% FPS
Windows安全中心 → 设备安全性 → 内核隔离 → 关闭"内存完整性"。CPU 密集型游戏收益最大（PUBG 正是）。
电源计划：卓越性能 +5-10%
管理员 PowerShell 运行 powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61，然后控制面板 → 电源选项 → 选"卓越性能"。
游戏模式 + HAGS +1-5% +低延迟
设置→游戏→游戏模式开；设置→系统→屏幕→图形→硬件加速GPU计划开（DLSS 帧生成必需）。

第二梯队：设置微调

NVIDIA 控制面板优化
电源管理模式=最高性能优先；着色器缓存=10GB；低延迟模式=开（别选超高）；纹理过滤-质量=性能。
关闭 Xbox Game Bar 录制
不录屏就关，省 1-3% CPU。设置→游戏→Game Bar。
关闭开机自启杂项
任务管理器→启动，只留杀毒+驱动控制台。
确认 DirectStorage
NVMe盘+Win11 已满足。Win+G → 设置 → 看 DirectStorage 是否启用。

第三梯队：谨慎/了解即可

禁用 Nagle 算法 仅 TCP 游戏有效
PUBG 用 UDP 无效，别折腾。只对魔兽/FF14 等 MMO 有意义。
关键认知这套配置瓶颈在 CPU 调度而非显卡——VBS 关闭 + 电源计划收益最大。Auto Super Resolution 仅骁龙 Copilot+ PC 可用，AMD 平台用 DLSS 3 帧生成代替。

显示器设置（解决画面发白）

关闭 Windows HDR 90% 概率是它
设置→系统→屏幕→"使用 HDR"关掉。HDR400 属入门级，Windows 开 HDR 后 SDR 内容整体发白泛灰是通病。
输出动态范围选"完整"
NVIDIA 控制面板→显示→更改分辨率→输出动态范围选"完整"（0-255）。"有限"（16-235）会让画面发灰发白。
确认 10bit 满血
NVIDIA 控制面板→输出颜色深度确认 10 bpc、RGB。只能 8bit 多半是线材问题——必须用 DP1.4 线（显示器自带）。
显示器 OSD 微调
亮度 70-80、对比度 50-60、伽马 2.2；关闭"动态对比度/OD加速"。
