# 装机优化工具

9800X3D + RTX 5080 装机全套指南：Win11 游戏优化清单、微星 X870E BIOS 教程、显示器设置、常用工具导航。

## 功能

- **BIOS 设置**：EXPO 内存超频、PBO、M-FLASH 更新 BIOS 三种方法
- **Win11 优化**：15 条游戏优化清单（关 VBS / 卓越电源 / HAGS 等），每条带预期收益
- **显示器设置**：解决 HDR400 画面发白四步排查
- **常用工具导航**：驱动下载、硬件检测、跑分、装机工具
- **进度追踪**：勾选清单自动保存到浏览器 localStorage，重开不丢
